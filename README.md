### ✨ What it does

- **Toolbar Badge** → Shows the first two octets of your IP in glowing magenta/cyan  
  Example: `192.168..`

- **Hover** → Full IP + location on mouse-over

- **Popup** → Big neon IP + location + timestamp + **live map** of your approximate position

- **Auto-refresh** every 60 seconds

- **Manual refresh** button

- Keeps last known data if offline

---

### 🗺️ Map
Interactive OpenStreetMap centered on your estimated location with a marker.

---

### 🚀 Install (10 seconds)

1. Open `chrome://extensions` or `brave://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this folder
5. Pin it to your toolbar

Done. Your IP is now watching you back.
